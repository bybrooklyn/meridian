# Production records

Milestone reviews, asset approvals, provenance checks, licensing decisions, and quality-review records belong here.

Records use the v0.5 registry identifiers and distinguish `Pass`, `Fail`,
`NotRun`, unsupported, occluded, redacted, waived, stale, and inconclusive
outcomes. Private Project Meridian evidence may be referenced by controlled
identifier and hash but must not be copied into the engine repository.
