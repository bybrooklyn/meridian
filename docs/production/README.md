# Production records

Milestone reviews, asset approvals, provenance checks, licensing decisions, and quality-review records belong here.

Records use the v0.5 registry identifiers and distinguish `Pass`, `Fail`,
`NotRun`, unsupported, occluded, redacted, waived, stale, and inconclusive
outcomes. Private Project Meridian evidence may be referenced by controlled
identifier and hash but must not be copied into the engine repository.

The [Meridian UI design brief review](MERIDIAN_UI_DESIGN_BRIEF_REVIEW.md)
records the non-normative input disposition. The
[UI mockup manifest](ui-mockups/mockups.json) and its 17 generated SVG outputs
form one visual consistency corpus for the future framework and editor. They are
specification/review artifacts, not evidence that represented domain behavior
is implemented. Regenerate them with `python3 scripts/generate_ui_mockups.py`.
