# Development notes

Use this directory for implementation notes, experiment results, prototype decisions, and platform-specific validation records. Experimental results must include measurements and the exact build/configuration used.

Each record should name its `WP-*` or `RG-*` owner, source checkpoint, capability
profile, hardware/OS/backend where relevant, corpus and build hashes, warmup and
cache state, known limits, and raw evidence location. A note is not normative
unless the owning v0.5 specification and ADR adopt it.
