# PEN-B03 — Flashlight Through Alpha-Tested Foliage

[Suite](README.md) · [Penumbra](../../MERIDIAN_SPECOMENT.md)

version 1.0 · `DefinitionOnly` · `Uncalibrated`

Purpose: isolate moving alpha-tested leaves/grass under a controlled flashlight
and shadow casters. Deterministic sweeps vary layer count, alpha coverage,
material diversity, light angle/range, wind motion, shadow tier, and temporal
settings. Capture lit/unlit edges, shimmer, ghosting, overdraw, cluster/light
counts, shadow cost, and lower-tier fallback. The generated recipe fixes seed,
counts, camera/light paths, hashes, profile, warmup, and cache state. Use the
complete shared report contract; no numeric gate exists before calibration.
