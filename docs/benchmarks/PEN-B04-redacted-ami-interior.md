# PEN-B04 — Redacted AMI Interior With Many Local Lights

[Suite](README.md) · [Redaction decision](../architecture/decisions/ADR-0016-redacted-private-benchmark-policy.md)

version 0.5 · `DefinitionOnly` · `Uncalibrated` · Private payload prohibited

Purpose: measure connected generated interiors with many local shadowed lights,
mixed warm/cold practical temperatures, deterministic partial light failures,
varied opaque/transparent/decal materials, occluders, and indoor/outdoor
streaming. The recipe fixes room graph, dimensions, material/light counts,
failure schedule, traversal/camera, capture markers, hashes, profile, warmup, and
cache state.

No AMI logo, document, narrative text, private route, or proprietary asset may
appear. The private game may supply only a redacted authority/corpus hash. A
private-content audit is release-blocking and unwaivable. Reports include the
complete shared fields plus cluster occupancy/overflow, light/shadow lists,
transparency/decal cost, exposure transitions, and visual comparison.
